# Security Policy

## Public Showcase Scope

This repository is a sanitized portfolio showcase and is not intended to contain production credentials, private infrastructure information, personal data, or confidential operational records.

## Reporting a Security or Privacy Issue

If you discover accidentally exposed sensitive information, a credential, personal data, or a security-sensitive detail, please **do not open a public issue containing the information**.

Instead, contact the repository owner privately through the contact information available on the GitHub profile and include only the minimum information necessary to identify the problem.

## Supported Versions

This showcase does not publish or support production software releases. Security fixes to the public materials are applied to the current repository content when needed.
