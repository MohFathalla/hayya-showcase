# HAYYA — Smart Student Pickup

> **A safer, smarter way to manage school dismissal.**

HAYYA digitizes the student pickup journey by connecting guardians, teachers, pickup teams and school administration through one coordinated workflow.

## The Challenge
School dismissal can depend on calls, paper lists and manual coordination. That creates delays, limited visibility and unnecessary handoffs during one of the busiest parts of the school day.

## The Solution
HAYYA creates a structured digital workflow from guardian arrival to controlled student handover.

## How It Works
**Guardian Request → Child Selection → Teacher Notification → Preparation / ETA → Pickup Zone → Handover Confirmation**

## Core Capabilities
- Guardian pickup requests
- Multiple children under one guardian profile
- Per-child pickup actions
- Teacher-controlled readiness / ETA
- Pickup-area confirmation
- Kiosk workflow for alternative access
- Administrative operational dashboard
- Daily activity visibility
- Structured handover workflow

## Designed Around People
**Parents** get a simple arrival workflow.  
**Teachers** receive clear pickup requests.  
**Pickup teams** coordinate handover.  
**Administrators** gain operational visibility.

## Technology
Web Application • Workflow Automation • SQLite with scalable database architecture • Role-Based Experiences
